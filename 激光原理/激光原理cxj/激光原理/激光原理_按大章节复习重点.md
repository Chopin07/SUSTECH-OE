# 激光原理与技术：按大章节复习重点

> 复习定位：考试以选择题、判断题为主，所以本整理只保留必要公式和判据，更强调概念、分类、条件、趋势关系和 PPT 标注内容。

## Ch1 Basic Principles of Lasers：激光基础

### 本章主线

激光的基础逻辑是：光子具有波粒二象性 -> 腔选择有限模式 -> 光与物质存在吸收、自发辐射、受激辐射三过程 -> 外界泵浦打破热平衡实现粒子数反转 -> 受激辐射带来相干放大 -> 增益超过损耗后形成自激振荡。

### 标注重点

- 驻波边界条件：腔内能稳定存在的模式必须满足相位差为 `2π` 的整数倍。
- `K` 空间中相邻允许模式的间隔决定模式所占“体积”；某频率附近的模式数 = 总模式体积 / 单个模式体积。
- 光学谐振腔从全封闭变为开放/半开放后，能稳定存在的模式减少；总能量一定时，模式越少，每个模式能分到的能量越多。
- 相干性：同频同相才可干涉；单色性越强，相干时间和相干长度越长。
- `A21` 只与原子本身有关；`W12 = B12 rho_v`、`W21 = B21 rho_v` 同时与原子和辐射场有关。
- 热平衡下满足 Boltzmann 分布；有外界泵浦时才可能打破热平衡，实现粒子数反转。
- 增益系数 `g` 与粒子数反转量 `Δn` 正相关；光强增大后会消耗反转粒子数，导致增益饱和。

### 选择/判断高频概念

- 光子能量 `E = hν`，动量 `p = hbar k`；光子有两个独立偏振态，服从 Bose-Einstein 分布，同一状态可容纳多个光子。
- “光模式”可以理解为“光子态”；模式越少，特定模式内的光子简并度越高，相干受激辐射越容易形成。
- 自发辐射相位和方向随机，不产生高相干光；受激辐射与入射光同频率、同相位、同传播方向，是光放大的核心。
- 受激吸收、受激辐射、自发辐射三过程总是存在，只是强弱不同。
- 粒子数反转是激光形成的必要条件，但还需要腔反馈和增益大于损耗。
- `Δn > 0` 对应放大，`Δn = 0` 对应透明，`Δn < 0` 对应吸收。
- 增益曲线 `g(ν)` 的半高宽就是增益带宽；损耗可看成负增益。
- 自激振荡条件可概念化记忆为：单程/往返增益必须补偿腔损耗，阈值附近 `g l = δ`。

### 易错判断

- “受激辐射产生的光与入射光相干”是对的；“自发辐射也与入射光同相”是错的。
- “热平衡下高能级粒子数自然大于低能级”是错的。
- “粒子数反转只靠升高温度即可实现”通常是错的；需要外界泵浦打破热平衡。
- “增益系数只由材料决定，与光强无关”只在弱信号近似下对；强光下会发生增益饱和。
- “腔只提供反馈，不参与选模”是错的；腔是激光器的主要选模元件。

## Ch2 Open Cavity & Gaussian Beam：开放腔与高斯光束

### 本章主线

Ch2 讨论激光器里“哪些光能在腔内稳定存在”和“这些光束长什么样”。核心包括：纵模/横模、腔损耗与 Q 值、ABCD 矩阵、稳定腔判据、自再现模、Hermite-Gaussian/Laguerre-Gaussian 模式、高斯光束参数和传输变换。

### 标注重点

- 横模：横截面上的空间光强分布，也就是光斑形状；纵模：腔内满足驻波条件的频率模式。
- 纵模间隔 `Δν = c / (2L')`；腔越短，纵模间隔越大。
- `Q` 值越大，腔损耗越小，光子寿命越长。
- ABCD 矩阵建立在近轴近似上，描述低阶/小角度光线。
- 稳定条件很重要：`|(A + D)/2| < 1`；对球面镜腔也常写作 `0 < g1 g2 < 1`。
- 自再现模：光场经过一轮传播和反射后，形状不变，只改变振幅和相位。
- 本征函数代表腔内横模分布；本征值的模与单程损耗有关，相位与谐振频率有关。
- 方形/矩形腔近似对应 Hermite-Gaussian 模式；圆形腔对应 Laguerre-Gaussian 模式。
- TEM00 是基模，镜面上为高斯分布，是重要考点。
- Fresnel number `N` 越大，衍射损耗越小；横模阶数 `m,n` 越高，衍射损耗越大。
- 共焦腔有模式简并：不同模式可能具有相同频率，但损耗不一定相同。
- 高斯光束的重要性质：波前可近似看成球面波，横向振幅/强度为高斯分布。
- `q` 参数用于描述高斯光束传播；知道 `q` 就能得到 `w(z)` 和 `R(z)`。
- 光束质量因子 `M^2`：理想基模为 1，越接近 1 光束质量越好。

### 选择/判断高频概念

- 腔损耗包括：透射损耗、衍射损耗、几何损耗、材料/调 Q 元件等其他损耗。
- 稳定腔：小角度偏离轴线的光线能被反复限制在腔内；非稳定腔：光线经过若干次反射会逃逸。
- 平行平面腔通常处在临界/不稳定边界，实际稳定性差。
- 只有对称共焦腔能得到严格解析解；一般稳定球面腔常通过等效共焦腔处理。
- HG 模式中，`m` 表示 x 方向零点/节线数，`n` 表示 y 方向零点/节线数。
- LG 模式中，径向阶数对应暗环数量，角向阶数对应角向节线数量。
- 高阶横模光斑更大、节线更多、衍射损耗更高，阈值也更高。
- 高斯光束在束腰处 `R = infinity`，波前近似平面；远离束腰时逐渐近似球面波。
- 单透镜不能把高斯光束变成真正的平面波；准直通常用望远镜结构改善发散角。

### 易错判断

- “横模决定频率，纵模决定光斑形状”是错的，正好反过来。
- “腔越长，纵模间隔越大”是错的，腔越短间隔越大。
- “高阶横模比基模更容易振荡”一般是错的，因为高阶横模损耗更大。
- “Fresnel number 越大，衍射损耗越大”是错的。
- “所有稳定球面腔都有无数个等效共焦腔”是错的；任意稳定球面腔只有一个等效共焦腔。

## Ch3 Resonant Interaction：电磁场与物质的共振相互作用

### 本章主线

Ch3 解释“增益介质为什么有频率带宽、为什么会饱和、不同频率之间如何竞争”。核心是谱线展宽、速率方程、三/四能级系统、均匀展宽增益饱和和非均匀展宽烧孔。

### 标注重点

- 谱线展宽要抓三个量：中心频率、线宽、线型。
- 均匀展宽：所有原子对谱线宽度内所有频率都有影响，且影响方式相同。
- 非均匀展宽：不同原子/离子/速度组只对部分频率有贡献，影响程度不同。
- 自然展宽线型是 Lorentz 型；与能级寿命有限和时间-能量不确定性有关。
- 碰撞展宽可理解为一种等效 lifetime 缩短；气体中常表现为压力展宽。
- Doppler 展宽来自原子热运动速度分布，线型是 Gaussian 型，属于非均匀展宽。
- 速率方程中 `S32`、`S10` 等是弛豫过程。
- 四能级系统中下激光能级快速弛豫，通常比三能级更容易实现粒子数反转。
- 均匀展宽下，强光会使整个增益谱一起下降；一个频率消耗反转粒子数，会降低其他频率的增益。
- 非均匀展宽下，强光主要在对应频率附近烧孔；Doppler 展宽驻波情形会形成对称双烧孔。

### 选择/判断高频概念

- 自然展宽、碰撞展宽、晶格振动展宽属于均匀展宽，典型线型为 Lorentz 型。
- Doppler 展宽、晶体局域场不均匀/缺陷导致的展宽属于非均匀展宽。
- 气体压力升高 -> 碰撞频率升高 -> 碰撞展宽增大。
- 固体增益材料中，晶格热振动常是重要均匀展宽来源；玻璃中局域环境差异会带来明显非均匀展宽。
- 谱线综合展宽是均匀和非均匀线型的卷积；哪一种线宽大，综合表现通常更接近哪一种。
- 考虑谱线展宽后，光频率不必严格等于中心频率，也能发生受激辐射，只是概率由线型函数决定。
- 发射截面/吸收截面在中心频率附近最大。
- 饱和强度在中心频率处最小，离中心频率越远饱和强度越大，饱和效应越弱。

### 易错判断

- “均匀展宽中，不同频率互不影响”是错的；均匀展宽会整体共享反转粒子数。
- “Doppler 展宽是 Lorentz 线型”是错的；Doppler 是 Gaussian 线型。
- “碰撞越频繁，线宽越窄”是错的。
- “自发辐射总概率因为谱线展宽而改变”通常按课件表达是错的；展宽改变频率分布，不改变总自发辐射概率。
- “非均匀展宽激光中只能单纵模输出”是错的；由于烧孔局部性，常可多纵模振荡。

## Ch4 Oscillation Characteristics：激光振荡特性

### 本章主线

Ch4 从速率方程进入实际激光振荡：什么条件下起振、哪些模式输出、输出功率怎么变、驰豫振荡如何产生、单模线宽为什么有限。

### 标注重点

- 起振需要两个条件：存在粒子数反转 `Δn > 0`，且增益大于损耗。
- 粒子数反转阈值 `Δnt` 是重要概念：只有超过阈值才能形成稳定激光。
- 高阶横模衍射损耗更大，因此增益阈值更高。
- 功率阈值与材料和腔有关：转换效率、受激发射截面、寿命、荧光线宽、增益体积、腔损耗等。
- 线宽与受激截面成反比；窄荧光线宽通常意味着更大截面、更低阈值。
- 均匀展宽下模式竞争图是重要考点：稳态理想情况下趋向单纵模，频率在增益曲线中心附近。
- 空间烧孔：局域性消耗增益，导致增益介质局部反转粒子数下降。
- 纵向空间烧孔来自驻波波腹处增益消耗；横向烧孔来自横模光强集中区域的增益消耗。
- 驰豫振荡本质：泵浦和受激辐射对 `Δn` 的影响不同步，又相互耦合。
- 泵浦增强会使驰豫振荡频率更高、阻尼更快。
- 主动腔线宽小于被动腔线宽，但自发辐射和噪声使真实激光线宽不可能为 0。

### 选择/判断高频概念

- CW 激光可用稳态代数方程近似；短脉冲激光是非稳态问题。
- 短脉冲泵浦 `t0 < τ2` 时，可忽略部分自发辐射/弛豫；长脉冲 `t0 >> τ2` 更接近 CW。
- 四能级激光阈值通常低于三能级，因为下激光能级不是基态且能快速排空。
- 腔损耗 `δ` 增大 -> 阈值增大；光学元件质量变差会提高阈值。
- 均匀展宽稳态激光中，一个模式开始振荡后会压低其他模式增益，导致模式竞争。
- 空间烧孔可以削弱均匀展宽下的单模竞争，使多纵模或多横模振荡成为可能。
- 气体原子热运动快，不易形成稳定空间烧孔；固体中离子被束缚，更容易形成空间烧孔。
- 非均匀展宽激光中，泵浦增强会使满足阈值的纵模数量增加。
- Lamb dip：Doppler 非均匀展宽中，中心频率处由于双向烧孔重叠，单模输出功率曲线出现凹陷。
- 理论线宽极限远小于实际线宽；实际线宽常由温度漂移、机械振动、折射率波动等决定。

### 易错判断

- “只要有粒子数反转就一定起振”是错的，还要增益超过损耗。
- “三能级系统比四能级系统阈值低”通常是错的。
- “高阶横模与基模阈值相同”通常是错的。
- “均匀展宽绝不会多模振荡”太绝对；空间烧孔会导致多模。
- “主动腔线宽为 0”是错的；自发辐射和噪声导致有限线宽。
- “输出功率总是随输出镜透过率单调增大”是错的；存在最佳透过率。

## Ch5 Amplification Characteristics：激光放大特性

### 本章主线

Ch5 讨论“有输入光时，增益介质怎样把它放大”。放大器没有必要自激振荡，重点是输入信号强弱、增益饱和、泵浦方式和放大器长度。

### 标注重点

- 放大器中的增益介质由泵浦激发，再放大入射信号。
- 按时间分：连续放大器、脉冲放大器、超短脉冲放大器；依据是入射脉宽与纵向/横向弛豫时间的关系。
- 工作方式分：行波放大器和再生放大器；再生放大器对谐振频率匹配更敏感。
- 功能分：前置放大器、功率放大器、线路放大器。
- 大信号放大时，中心频率附近最先接近饱和、增长变慢；旁边频率增长相对更快，输出谱会展宽。
- EDFA 小信号增益与泵浦光强 `Ip0` 和放大器长度 `l` 有关，与信号强度无关。
- EDFA 存在最佳长度：太长时泵浦低于阈值会造成信号衰减；太短时泵浦没有充分利用。
- 脉冲放大器中，能量增益定义为输出光子流/输入光子流。
- 弱初始入射信号：能量增益与信号强度无关，随长度和初始反转粒子数指数增加。
- 强初始入射信号：增益饱和明显，能量增益随长度和反转粒子数近似线性增加，不再指数增加。
- 有损耗且长度很长时，输出趋于饱和；继续加长不一定有效。

### 选择/判断高频概念

- 前置放大器工作在弱信号区，强调小噪声；功率放大器常工作在饱和区，强调大输出功率。
- 均匀横向泵浦放大器中，`Δn`、`g0`、`Is` 可近似为空间常数。
- 纵向泵浦光纤放大器中，泵浦和信号沿 z 方向变化，因此 `Δn(z)`、`g0(z)`、`Is(z)` 都随位置变。
- EDFA 属于连续激光放大器，因为通信信号作用时间远短于 Er 离子纵向弛豫时间，反转粒子数只在稳态附近小幅波动。
- 强信号放大导致脉冲前沿和顶部增益不同，可能出现脉冲变窄和波形畸变。
- 对有损脉冲放大器，提高输出能量不能只靠无限增加长度，更有效的是提高初始反转粒子数、降低损耗并优化长度。

### 易错判断

- “放大器一定要满足自激振荡阈值”是错的；放大器可以没有谐振反馈。
- “小信号增益随输入信号强度增加而增加”是错的；弱信号区增益基本与输入强度无关。
- “强信号放大仍然指数增长”是错的；饱和后常转为近似线性或趋于饱和。
- “EDFA 越长越好”是错的，存在最佳长度。
- “大信号饱和会让中心频率处增长更快”是错的；中心更容易饱和，增长变慢。

## Ch6 Control & Improvement of Laser Performance：激光性能控制与改善

### 本章主线

Ch6 是应用型章节，核心是“如何让激光更单模、更稳定、更短脉冲、更高峰值功率”。重点包括选模、稳频、Q 开关和锁模。

### 标注重点

- 选模目的：基横模和单纵模具有更好的空间相干性和时间相干性。
- 横模选择的物理基础：不同横模衍射损耗不同；目标是只让 TEM00 满足阈值。
- 小孔光阑可利用腔内损耗差筛选横模，只保留 TEM00。
- 纵模选择目标：在特定跃迁线范围内实现单纵模。
- 纵模选择规则：扩大相邻纵模之间的增益差，或人为引入损耗差。
- 短腔法：减小腔长，增大纵模间隔，使不想要的纵模得不到有效增益。
- F-P 标准具可引入频率选择性损耗，是常见纵模选择元件。
- 稳频本质：稳定光学腔长 `L' = nL`；温度、振动、折射率、压力、湿度、电流都会影响频率。
- 稳频闭环：选参考频率 -> 获取误差信号 -> 伺服控制腔长。
- Q 开关：先让腔处于低 Q/高损耗以积累反转粒子数，再快速切换为高 Q/低损耗，释放巨脉冲。
- 主动 Q 开关由外部驱动调损耗；被动 Q 开关由腔内光强自动改变损耗。
- 锁模：让多个纵模具有固定相位关系，输出等间隔超短脉冲序列。

### 选择/判断高频概念

- 横模选择方法：腔型设计、小孔光阑、非稳定腔、精细调腔。
- 非稳定腔适合高增益激光器，可用于获得大模体积、高功率、较好光束质量。
- 纵模选择方法：短腔、F-P 标准具、行波腔、复合腔、DFB/DBR 结构等。
- 稳频方法包括 Lamb dip、饱和吸收、Zeeman 吸收、F-P 标准具等。
- 饱和吸收稳频可形成反 Lamb dip，频率稳定性和复现性较好。
- Q 开关方法：旋转镜、电光 Q 开关、声光 Q 开关、可饱和吸收体。
- 电光 Q 开关利用 Pockels/Kerr 效应改变偏振/反射损耗；声光 Q 开关利用衍射损耗；可饱和吸收体利用吸收损耗。
- 自由运行多纵模激光相位随机，输出是随机叠加；锁模后相位固定，形成周期性短脉冲。
- 锁模脉冲间隔 `T0 = 2L'/c`，由腔往返时间决定。
- 参与锁模的模式数越多，峰值功率越高，脉宽越窄；脉宽量级约为 `1 / ΔνF`。
- 腔倒空与 Q 开关思路相反：通过快速切出腔内已积累的脉冲能量来提高单脉冲输出。
- CPA 啁啾脉冲放大：先展宽脉冲，放大后再压缩，用于避免超短脉冲直接放大时峰值功率过高。

### 易错判断

- “选横模就是选频率”是错的；横模主要关乎空间分布，纵模主要关乎频率。
- “短腔会减小纵模间隔”是错的；短腔会增大纵模间隔。
- “稳频只需要稳定温度”不完整；还要考虑振动、折射率、压力、湿度、电流等。
- “Q 开关是为了降低峰值功率、延长脉冲”是错的；Q 开关用于获得高峰值、短而强的巨脉冲。
- “被动 Q 开关需要外部电信号驱动”是错的；被动 Q 开关依靠腔内光强改变吸收。
- “锁模只是把一个纵模变强”是错的；锁模依赖多个纵模相位锁定。

## 最后复习建议

- 选择题优先背：定义、分类、条件、趋势关系。
- 判断题优先练：把“越大越小”“是否只与材料有关”“是否一定/总是/只要”这类绝对表述改成条件表述。
- 本课最容易混淆的三组概念：
  - 横模 vs 纵模：光斑形状 vs 频率驻波。
  - 均匀展宽 vs 非均匀展宽：整体共享增益 vs 局部频率/速度组烧孔。
  - Q 开关 vs 锁模：积累能量后释放巨脉冲 vs 多纵模相位锁定形成超短脉冲列。
