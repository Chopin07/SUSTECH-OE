## 💬 课程评价与选课指南 (Course Reviews)

为了帮助学弟学妹们在选课、排课时少走弯路，本仓库特设立**课程评价**板块。评价内容仅代表个人（或贡献者）的主观体验，包含**课程难度、给分情况、实验（Lab）工作量、授课风格以及避坑建议**。

欢迎大家通过 **Issue** 或 **Pull Request** 补充你的课程心得！

### 🌟 快速评价索引（示例）
> 💡 *提示：点击下方课程名称可跳转至详细评价或对应资料文件夹。*

| 课程分类 | 课程名称 | 综合推荐指数 | 一句话避坑/核心心得 |
| :--- | :--- | :---: | :--- |
| **电路与电子基础** | 模拟电路实验 / 数字系统设计 | ⭐⭐⭐⭐⭐ | 务必提前调通仿真，Verilog 时序逻辑要严谨，冲刺高分利器。 |
| **光电与半导体** | 第三代半导体 / 光电智感 | ⭐⭐⭐⭐⭐ | 结合前沿工业界应用，大作业含金量极高，建议组队选好队友。 |
| **通识与人文** | 西方哲学导读 / 合唱 | ⭐⭐⭐⭐ | 极佳的绩点拉分/调剂课程，注重课堂参与度和结课论文。 |

### 📝 课程评价详情模板 (Review Template)

如果你想为某门课程撰写评价，建议包含以下维度（可直接在对应课程文件夹下新建 `Review.md` 或直接写在下方）：

#### 📘 [课程名称] | Course Name
* **授课教师**：XXX 老师
* **推荐指数**：⭐⭐⭐⭐⭐（5/5）
* **硬核程度/工作量**：高 / 中 / 低
* **给分情况**：超好 / 严格 / 奶人
* **课程心得与避坑指南**：
  > 1. **考核形式**：通常由 期末考试 (X%) + 实验报告 (X%) + 大作业/Presentation (X%) 组成。
  > 2. **避坑经验**：这门课的 Lab 耗时较长，尤其是数据处理部分，建议熟练使用 Origin 或 MATLAB 自动化脚本。期末复习时，老师 PPT 上的例题和概念推导是重中之重。
  > 3. **收获**：不仅能学到扎实的理论，对后续参加光电设计竞赛、机器人赛事、或者走学术科研路子的微纳器件加工/成像算法都有极大的奠基作用。

## 🛠 使用说明

你可以通过课程文件夹查找对应资料。不同课程文件夹下可能包含：

- 课程笔记
- 作业与参考解答
- 实验数据与实验报告
- 课程展示 PPT
- 复习资料
- 其他个人整理文件

由于资料来源于个人学习过程，部分内容可能存在不完整、格式不统一或错误之处，请结合课程要求、教材和老师发布的最新资料自行判断。
