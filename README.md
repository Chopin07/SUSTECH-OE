# SUSTECH-OE

南方科技大学光电信息科学与工程（个人）课程资料汇总。

本仓库用于整理本人在 SUSTech 光电信息科学与工程相关课程中的学习资料，包括课程笔记、实验报告、作业、展示材料、复习资料等内容。资料仅供学习交流与参考，请勿直接用于提交作业或其他违反学术诚信要求的用途。

## 使用说明

你可以通过课程文件夹查找对应资料。不同课程文件夹下可能包含：

- 课程笔记
- 作业与参考解答
- 实验数据与实验报告
- 课程展示 PPT
- 复习资料
- 其他个人整理文件

由于资料来源于个人学习过程，部分内容可能存在不完整、格式不统一或错误之处，请结合课程要求、教材和老师发布的最新资料自行判断。
